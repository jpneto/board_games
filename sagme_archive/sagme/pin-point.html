Pin Point

Date: 2026-12-08 17:23 | Tags: new games, moku

Pin Point is a 1993 game by Oliver Cockell, published by Oliver Games.

The game is played in this board, 

 
Each player has 25 tokens (the game can be played by 2-4 persons)

All tokens have a black side

This is a scoring game where an unnecessarily complex set of patterns -- namely lines, squares and crosses, that might or might not cross grid lines -- value different points. 

Here are the official rules:

 

The original game has hidden information, but it is easily adapted by distributing all available tokens randomly at the setup stage. Afterwards, this variant becomes a combinatorial game.

The idea of jokers (the black side) is an interesting twist to avoid playing too many opponent's pieces. But the idea only works well because the rules allow each player to use them up to four times during a match. An early use of a dagger-like ludeme.
