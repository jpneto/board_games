Forma

Date: 2028-09-08 13:08 | Tags: old games, connection, tile games

Forma is a 1973 game by H. J. Geesink, published at Otto Maier Verlag.

 

The game is played on a 20x20 board, initially empty.

There is the following material:

  • a White piece (the tower)
  • 25 gray squares (the obstacles)
  • 22 tiles for each one of the four colors (red, green, black, yellow)
  • 35 markers for each one of the four colors

Each tile set contains: two unit squares, one domino, the two distinct trominoes, the five distinct tetrominoes, and the twelve distinct pentominoes (for a total area of 90 unit squares).


The game is for two to four players. For a two player game, each player uses the tiles and markers of two colors.

Rules:

  • The first player drops as many gray obstacles as he wishes, and also the tower (every piece should not be adjacent to each other) [it seems fairer this to be a job for both players]
  • On his turn, the player drops one friendly tile on empty squares (any combination of flips and rotations are valid)
  • Every turn, the player adds to his score, namely:
    • The dropped piece is worth its area in unit squares
    • Each isolated empty square that gets surrounded, scores 10 points (a marker is placed on top)
      • note: surrounded areas of two or more empty squares do not score
      • the previous pieces that help surround the empty square can be from the opponent
    • Each obstacle that gets surrounded by only friendly pieces, scores 10 points (it is possible to use edges to help surround obstacles)
    • If a new path between opposite edges is created, it scores 50 points
      • diagonal tiles are not connected, but friendly markers can also be used in the path definition
      • a player can have two or more paths to the same pair of edges, but they cannot touch each other
      • if there are already paths connecting the other pair of edges, this new path only scores if it shares just one square with each one of those paths
    • If a player surrounds the tower, ir scores 50 points
      • the previous pieces that help surround the tower can be from the opponent
  • Wins the player with highest score
    • unused tiles are scored as negative points
