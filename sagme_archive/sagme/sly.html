Sly

Date: 2027-01-08 13:53 | Tags: old games, game system

Sly, aka Blockade, is a 1975 game by Sid Sackson, published at Buchholz Verlag (among others).

The game comes with four sets of one cylinder, four triangles and six squares (in four different colors).

Sly is sold as a game system, the ruleset includes six games that can be played with the available material:

  • Solitaire Sly - which is a puzzle for one player
  • Sniggle - A Halma-like game
  • Line Up - A moku game
  • Blockade - A path making game to deliver the King to the other side of the board
  • Empire - A chess-like positional game
  • Gateway - A morris-like game in reverse, building a shape makes a new piece to be dropped

The rules for these six games can be read here.

This is a new batch of games for the same board of Realm, an earlier Sid Sackson creation (which already included several other variants around the main ruleset).

At BGG there are references for a series of youtube videos that explain these games.

Also, from BGG, a review for Antonio Recuenco Muñoz:

Sly's a collection of games rather than a system (there's no common distinctive qualities in pieces or board for any couple of games within the set), all of which are very different from each other, in character as much as in difficulty.

The first three games are easier: it takes only a couple of tries to crack the Solitaire, Line Up is a short and punchy development on Tic-Tac-Toe that lives off its restrictive piece movement rule, and Sniggle is a quite cunning race game that doesn't allow many ways to follow but always brings close endings for any number of players, making it the most replayable of these three.

The latter three games are a different kind, and all of them nearly equally rewarding - Blockade reuses the idea behind Sid's earlier game Network, Empire's an interactive and concise but relatively deep game where players battle for central positions of the board, and even though Gateway does bring an aftertaste of Realm it's the strangest, most original game of the bunch.

It's difficult to avoid comparisons to Realm, Sly's older brother. Overall, Sly doesn't quite reach the former's level: the set of games is not cohesive, and these might be more elegant but less complex as well, especially considering Realm's "main course". Still, even considering Sly is just the sum of its parts it makes for very nutritious playing time.
