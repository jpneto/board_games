Ishi

Date: 2026-12-11 21:30 | Tags: old games

Ishi is a 1974 game by Alex Randolph, published at Otto Maier Verlag and Ravensburger. 

The game is played on a equilateral triangle of size 10:

Each player has 40 pieces. 

A group here is a chain of connected pieces of either color.

Rules:

  • Initially, one player drops seven pieces of either color on the board forming one group
  • Phase 1: On each turn, if the previous player dropped N pieces, then the player must drop a group of M pieces (on empty positions) where M is in {1, 2, 3, ..., N-1, N+1}
    • There's an exception for N=1, then M is in {1,2}
    • The player that drops the last piece loses phase 1
    • The final board (which is now full) is the starting place for phase 2.
  • Phase 2: On each turn, the player removes any number of pieces of the same color (either white or black) that belong to the same group
    • The player that removes the last piece loses phase 2
  • Wins the player that wins phase 1 and 2, otherwise the game is a draw.

This is a NIM-like game. In some game sets, Ichi came together with the game of Go (the Ishi triangular board was on the back of the Go board).
