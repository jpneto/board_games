Alternator

Date: 2029-01-05 10:23 | Tags: new games, pencil & paper

Alternator is a 2003 game by Gregory K. Van Patten.

The game is played on a 8x8 board, initially empty.

Definition:

  • A node is a square marked with a dot
  • Nodes can be connected to other orthogonally nodes by branches
  • A tree is a branched sequence of one or more nodes, with exactly one branch that connects one of those nodes to an empty square; this branch is called the root and its color defines the tree's ownership
  • A tree's size is the number of its nodes

Rules:

  • On her turn, the player either:
    • passes her turn
    • creates a new friendly tree
    • adds a new friendly node to an existing friendly tree by extending its root
  • A new root might connect to a different second root (of either color), however this is only possible if the second tree is smaller in size
  • When both players pass on consecutive turns, the game ends. Wins the player with the largest sum of her trees' sizes.
    • to compensate first-player advantage, assume a komi of 3.5 points added to the second player's final score

an endgame position

This is a pencil and paper game.
