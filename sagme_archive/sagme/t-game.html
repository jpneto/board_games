T-game is a late 1970s game by Christian Freeling.

Here are the rules, as presented in the book Five Minute Games by David Pritchard:

This game came as a reply to the L-game, well-known at that time, by trying to propose a better game design.

I asked Freeling about the game and he replied:

So far as I remember the game it was flawed so I ditched it. De Bono's work was popular among hippies back then, but anyone could see that the L-game if played played optimally would go on forever. So the idea of an improvement was fairly obvious but in retrospect is wasn't so easy.

Later, further along the game inventing trail, I would probably have realised that making such a small game both balanced and decisive would be near impossible. But I wasn't hindered by lack of knowledge or insight back then.
