Gounki

Date: 2029-01-19 13:51 | Tags: new games, stack pieces

Gounki is a 1997 game by Christophe Malavasi.

The game is played on a 8x8 board with the followin g setup,

Each player has 16 pieces, eight circles and eight squares (in the picture above that would be the stars).

This is a stacking game, where the goal is place a piece behind the opposite row. The rules are a bit extensive, so you can read them here.

The game had a dedicated website that became defunct around 2014. Fortunately we still have the Wayback Machine!
