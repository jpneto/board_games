Cluster

Date: 2026-12-22 08:53 | Tags: old games

Cluster is a 1973 game by Philip Shoptaugh, published at Four Generations.

The game is played on the following board,


game setup

Each player has eight pieces, four short and four long. 

The board has 20 shallow positions and 26 deep positions. A long piece in a deep position will look the same as a short piece in a shallow position.

Rules

  • On his turn, the player picks a friendly piece that either: 
    • moves into any adjacent empty position.
    • jumps a line of pieces, regardless of color and height, landing in the first empty position (the first jumped piece needs to be adjacent before the jump)
  • The goal is to have all friendly pieces in the same group and with all the pieces’ tops on the same level.
    • this means that all tall pieces must be in deep positions, and all short pieces must be in shallow positions, i.e., all pieces of the same color must appear to be of the same height.

Cluster is an early unification game. To my knowledge, it is the second game with this goal, after the seminal 1969's Lines of Action. The mechanism of height is very nice, an original touch to the original unification game genre, that only had four years back then.
