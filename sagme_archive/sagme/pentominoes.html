Pentominoes

Date: 2028-06-16 14:35 | Tags: old games, tile games

Pentominoes is a 1953 game by  Solomon W. Golomb, initially self-published.

The game is played on a 8x8 board,

The game comes with the twelve pentominoes pieces, initially in the reserve (the board starts empty),

Rules:

  • On his turn, the player picks one piece from the reserve and drops it without overlapping other pieces already on the board
  • Wins the last player to move

The board has 64 squares, while the area of all pieces just sum to 60. However, some useless empty areas will be created, and so it's quite possible to win before dropping all pieces.

The game had many editions, and some iterations, like 1960's Pan-Kai (by Alex Randolph) that uses a 10x10 board and each player has a complete set (so an area of 100 to place 120 units of area),

This is a very different game. The original is an impartial game (pieces are shared), while Pan-kai is partizan, i.e., each player has his set of pieces and, thus, a different set of available moves.

Another is Universe, also by Alex Randolph, with an extended board to be played up to four players,


cf. this doc more information and some puzzles

This game has the cover theme of Stanley Kubrick's 2001 which probably is connected to the story where Kubrick presented a pentominoes puzzle to Arthur C. Clark, during the writing of the movie's first draft.

This game is dated 1966 in BGG, but that seems an anachronism, since the movie 2001 only premiered in 1968 (perhaps some pre-released marketing?).

There is another game, associated with Universe, that is called Philp. According to BoardSpace.net:

Players take turns placing a piece anywhere on the board.  All adjacent pieces of the opposite color are flipped to match the newly placed piece. The player with the most squares his color when no more pieces can be placed [wins the game].

To my knowledge, Pentominoes is the first game using polyominoes larger than dominoes (Martin Gardner's Cram, from 1950, is an abstract game using dominoes).
