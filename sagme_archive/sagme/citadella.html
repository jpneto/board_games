Citadella

Date: 2029-11-30 16:05 | Tags: old games, tile games

Citadella is a 1983 game by Fred Horn, published at Gerhards Spiel und Design.

The game is played on a 9x9 board, with the following setup:


Each player has a set of five tridimensional tiles (see below).

The goal is join all friendly pieces in a single 3x3 area.

There is an obvious drawish strategy, just block one of the 1x1 pieces of the adversary that start at the corner. An extra rule should be added to handle this case. One example would be to allow any piece to jump over enemy pieces, if they get blocked by the adversary.
